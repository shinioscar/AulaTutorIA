# Referencias visuales UX-2 de AulaTutor IA

Estos cuatro mockups son referencias conceptuales, NO capturas de la aplicación ni diseños funcionalmente vinculantes.

1. `01_mis_clases.png`: biblioteca de tarjetas, jerarquía, filtros, accesos de creación, estados.
2. `02_creacion_con_ia.png`: formularios mínimos, pasos progresivos, vista previa y panel lateral.
3. `03_tarjetas_estudiante.png`: un ejercicio por pantalla, ayudas bajo demanda, retroalimentación en superposición.
4. `04_supervision_docente.png`: indicadores basados en datos reales, resúmenes, gráficos y panel de detalle con pestañas.

Conservar identidad visual y temas Light/Dark existentes. No implementar literalmente funciones inventadas en estas imágenes: venta de planes, foros, notificaciones, cargas de documentos, arrastrar y soltar, puntuaciones oficiales, promedios o chats libres no autorizados. Las imágenes contienen datos ilustrativos que NO deben mostrarse como estadísticas reales. Las soluciones y pistas futuras NO se exponen en el cliente antes de autorizarse. Mantener permisos y privacidad por rol.

Entrega recomendada: colocar el contenido descomprimido en `F:\AulaTutorIA\docs\design\references\ux-2\` para que Codex pueda inspeccionarlo; consultar politica de Git antes de versionar estas imagenes, ya que son material de referencia y no assets de produccion.
