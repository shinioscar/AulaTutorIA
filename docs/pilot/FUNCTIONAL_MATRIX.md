# Matriz funcional del piloto

Las verificaciones y cifras ejecutadas se cierran en
[ITERATION_9](../iterations/ITERATION_9.md); esta matriz describe alcance y límites.

| Capacidad | Evidencia reproducible | Límite |
|---|---|---|
| Identidad/grupos | HTTP HTTPS, E2E registro/aprobación, grupo SQL ficticio | No confirmación/recuperación/MFA reales |
| Creación manual | UI crea/edita/guarda; fixture completa contenido canónico mediante API | No se midió tiempo de autoría humana completa |
| Generación integrada | Propuesta Mock aplicada, simulada; edición docente explícita del contenido SQL | Mock genérico, sin calidad curricular atribuida |
| Importación externa | Prompt V2 personalizado, JSON de referencia, vista previa, constructor | ChatGPT real no probado/automatizado; V1 conservado por regresión |
| Versiones/publicación/asignación | Tres versiones publicadas y asignadas por el mismo sistema | No publicación ni selección de versión implícitas |
| Clase conversacional | Dos alumnos SQL completan en integración; UI conversacional en regresión | 21 invocaciones Mock del guion SQL; no equivalencia con LLM |
| Clase precargada | Dos perfiles SQL en integración y tarjetas de navegador | Ayudas/feedback requieren revisión humana de contenido público |
| Evidencias/avance | Misma versión, intentos distintos, pausa/GET/reanudación | Coincidencia/entrega no certifica dominio; diez intentos por ejercicio |
| Refuerzo | Ejercicio complementario conversacional y sugerencias precargadas | No sustituye actividades obligatorias |
| Evaluación final | Referencias a intentos enviados, reporte local separado, replay | Preliminar; no comprende ni verifica Code mediante ejecución |
| Orden de reportes | Guion conversacional genera reporte IA antes de cerrar; precargado lo solicita después de Completed | Conserva comportamiento previo; no amplía regeneración del conversacional tras su resumen local |
| Supervisión | Cohorte vigente, objetivos/casos, observaciones IA y feedback humano | Sin chat autónomo ni acceso por rol Admin a evidencia privada |
| Cuota/caída/reintento | Proveedor controlado y HTTP handler, error UI staged, contexto durable | No disponibilidad ni latencia real de Groq demostradas |
| Reinicio | API detenida/reiniciada con estado PostgreSQL y replay | Ensayo local, no recuperación de desastre de producción |
| UI | Light/Dark 320/390/1440, foco/teclado, capturas y ancho medido | No entrevistas ni certificación WCAG |
| Operación | Demo retenida opt-in y limpieza con propiedad validada | Temporal/ficticia; no respaldo durable ni seed de principal |

No se incluyen diagnósticos precargados completos, modo híbrido avanzado, nuevos
proveedores, notas oficiales, código ejecutable ni integraciones universitarias.
